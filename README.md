# Ignas Malewa — Cybersecurity Portfolio

A clean, responsive portfolio website focused on Android application security, mobile penetration testing, reverse engineering, digital forensics, and network security.

## Structure

```text
ignas_portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
```

## Run locally

Open `index.html` in a browser.

For a simple local server:

```bash
cd ignas_portfolio
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000
```

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload all portfolio files.
3. Open repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)`.
7. Save.
